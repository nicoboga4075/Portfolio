🖥️ CRM Elphicom

{% include "switcher.html" %}

Plateforme CRM développée pendant 3 mois, lors de mon stage de fin d’études chez Soft Concept, éditeur de logiciels lyonnais spécialisé dans les solutions d’enquêtes (satisfaction, baromètres sociaux, enquêtes RH)

📝 Présentation

Elphicom est une société spécialisée dans la téléphonie et les services d’opérateur, basée à Avignon et à Vienne. Ce CRM permet de gérer efficacement : les clients et prospects, les contrats et documents associés, le suivi des appels et des interventions.

🛠️ Technologies utilisées

  • HTML, CSS, JavaScript
  • Outils internes : {% include "soft-concept-tools_fr.html" %}

🗂️ Structure de l’application

  • 📇 Clients et prospects : consultation, modification, suppression (uniquement pour les prospects)
  • 📃 Contrats : gestion avec code couleur (expiré, à surveiller, actif), renouvellement et suppression
  • 📞 Appels : gestion des historiques avec date, interlocuteur, motif, suite à donner
  • 📑 Bibliothèque de documents : fichiers Word, Excel, PDF...

⚙️ Fonctionnalités complémentaires

  • 📑 Fiches clients détaillées issues d'Ethnos : interlocuteur, SIRET, applications liées (Zendesk, Forest)
  • 📋 Rapports d’intervention terrain via Mobi-Survey (mode off-line)
  • 👥 Gestion des utilisateurs (Administrateur, Responsable, Commercial)

📈 Utilisation

L’application est utilisée quotidiennement par une vingtaine de collaborateurs pour le suivi client et la gestion commerciale et technique.
