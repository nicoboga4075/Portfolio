🖥️ JCA Sushi Robots

{% include "switcher_en.html" %}

E-learning platform developed over 6 months for Sushi Robots, on a permanent contract at Soft Concept

📝 Presentation

The application (Japanese Cuisine Academy) is designed to train sushi machine users through interactive modules.

🛠️ Technologies used

  • C#, HTML, CSS, JavaScript
  • Internal tools:
    • Net-Survey: questionnaire creation
    • Ethnos: survey data analysis
    • Web Reports: application development and deployment

🗂️ Application structure

👨‍💼 Administrator Profile (Sushi Robots)

  • 👥 Clients: manage sites
  • 📊 Dashboard: global view of the activity of all the clients
  • 🎓 Modules: create and manage training content (MCQ, videos, images)

🏢 Client Profile (e.g., Sushi Shop)

  • 🏬 Establishments: manage restaurants
  • 📊 Dashboard: indicators for each location
  • 📖 User guide: documentation and machine catalog
  • 📧 Contact: Sushi Robots support

🍽️ Establishment Profile (e.g., Sushi Shop Vitton)

  • 👤 Staff: manage employees
  • 📊 Dashboard: track employee scores and progress
  • 📖 User guide: documentation and machine catalog
  • 📧 Contact: Sushi Robots support

👩‍🍳 Employee Profile

  • 🎓 Modules: access assigned training modules, take scored quizzes
  • 📊 Dashboard: personal progress tracking
  • 📖 User guide: documentation and machine catalog

⚙️ Additional features

  • 🌐 Bilingual interface (FR / EN)
  • 🔐 Access rights management (4-level hierarchy)
  • 🛠️ Machine and training assignment

📈 Usage

  • 👉 Online training for sushi machine users
  • 👉 Performance tracking by brand, location and employee
  • 👉 Modular contents updated via ZIP archives
