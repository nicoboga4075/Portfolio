🖥️ JCA Sushi Robots

EN FR

Plateforme d'e-learning développée pendant 6 mois pour Sushi Robots, en CDI chez Soft Concept

📝 Présentation

L'application (Japanese Cuisine Academy) a pour but de former les utilisateurs de machines à sushi via des modules interactifs.

🛠️ Technologies utilisées

  • C#, HTML, CSS, JavaScript
  • Outils internes :
    • Net-Survey : création de questionnaires
    • Ethnos : analyse de données collectées
    • Web Reports : développement et déploiement applicatif

🗂️ Structure de l’application

👨‍💼 Profil Administrateur (Sushi Robots)

  • 👥 Clients : gestion des enseignes
  • 📊 Tableau de bord : vue globale sur l’activité de tous les clients
  • 🎓 Modules : création et gestion des formations (QCM, vidéos, images)

🏢 Profil Client (ex : Sushi Shop)

  • 🏬 Établissements : gestion des restaurants
  • 📊 Tableau de bord : indicateurs sur les établissements
  • 📖 Guide d’utilisation : documentation et catalogue machine
  • 📧 Contact : support de Sushi Robots

🍽️ Profil Établissement (ex : Sushi Shop Vitton)

  • 👤 Collaborateurs : gestion des employés
  • 📊 Tableau de bord : suivi des scores et progression des collaborateurs
  • 📖 Guide d’utilisation : documentation et catalogue machine
  • 📧 Contact : support de Sushi Robots

👩‍🍳 Profil Collaborateur

  • 🎓 Modules : Consultation des modules de formation attribués, réalisation de QCM notés
  • 📊 Tableau de bord : suivi personnel de progression
  • 📖 Guide d’utilisation : documentation et catalogue machine

⚙️ Fonctionnalités complémentaires

  • 🌐 Interface bilingue (FR / EN)
  • 🔐 Gestion des droits d'accès (hiérarchie à 4 niveaux)
  • 🛠️ Affectation des machines et des formations

📈 Utilisation

  • 👉 Formation en ligne pour les utilisateurs de machines à sushi
  • 👉 Suivi des performances par enseigne, établissement et collaborateur
  • 👉 Contenus modulables et mis à jour via des archives ZIP
