🖥️ CRM Elphicom

EN FR

Plateforme CRM développée pendant 3 mois, lors de mon stage de fin d’études chez Soft Concept, éditeur de logiciels lyonnais spécialisé dans les solutions d’enquêtes (satisfaction, baromètres sociaux, enquêtes RH). J’ai ensuite assuré sa maintenance durant mon CDI de 2 ans et demi.

📝 Présentation

Elphicom est une société spécialisée dans la téléphonie et les services d’opérateur, basée à Avignon et à Vienne. Ce CRM permet de gérer efficacement :

  • Les clients et prospects
  • Les contrats et documents associés
  • Le suivi des appels et interventions

🛠️ Technologies utilisées

  • HTML, CSS, JavaScript
  • Outils internes :
    • Net-Survey : création de questionnaires
    • Ethnos : analyse de données collectées
    • Web Reports : développement et déploiement applicatif

🗂️ Structure de l’application

  • 📇 Clients et prospects : consultation, modification, suppression (uniquement pour les prospects)
  • 📃 Contrats : gestion avec code couleur (expiré, à surveiller, actif), renouvellement et suppression
  • 📞 Appels : gestion des historiques avec date, interlocuteur, motif, suite à donner
  • 📑 Bibliothèque de documents : fichiers Word, Excel, PDF, etc.

⚙️ Fonctionnalités complémentaires

  • Gestion des utilisateurs et des listes déroulantes
  • Fiches clients détaillées : interlocuteur, SIRET, applications liées (Zendesk, Forest)
  • Rapports d’intervention terrain via Mobi-Survey (mode off-line)

📈 Utilisation

L’application est utilisée quotidiennement par une vingtaine de collaborateurs pour le suivi client et la gestion commerciale et technique.
