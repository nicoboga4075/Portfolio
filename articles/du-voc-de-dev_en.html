From the dev vocab
In the software development world, we often cross words like framework, library, package and module... While these words are sometimes, through misuse of language, used as synonyms in technical discussions, they are quite distinct concepts. Each plays a specific role in how developers structure, organize and automate their projects. To better understand these differences, this article provides a clear and accessible overview of these concepts, illustrated through concrete examples such as Angular, Selenium, Numpy and the Python's math module. The goal is to choose the right tool at the right time, based on the needs and context of the project.

Framework

A framework is a complete environment that provides a predefined architecture for developing applications. It imposes rules, conventions and a workflow that the developer must follow. The idea is to standardize development and reduce errors thanks to a rigid structure.

ASP.NET Core (C#)

ASP.NET Core is powerful, flexible and interoperable (Linux, MacOS and Windows), making it an excellent choice for modern development (web applications, APIs, or microservices). It supports large-scale and critical applications for large businesses such as Microsoft and is supported by the large Stack Overflow community. Its modular design allows you to choose the components you need and it has robust security features to protect you from common vulnerabilities (OWASP). However, even if .NET has become easier to use, early-stage developers might find it more difficult than the frameworks associated with languages like Python or JavaScript, described below. Since the release of .NET 5 in November 2020, the "Core" has officially disappeared from the name.

Flask (Python)

Flask, used by Netflix, has been known for its ease of use since its inception in 2010. Unlike “battery-included” frameworks like Django used by Instagram, Flask has a minimalist kernel, making it adaptable to a variety of projects, from simple REST APIs to microservices to more complex web applications. This gives developers flexibility but also requires them to make more decisions about architecture and component selection. This can be an advantage for experienced developers who take advantage of control but it can be difficult for juniors who are penalized by the lack of built-in features. Furthermore, while Flask adequately addresses common security needs, it requires developers to be more pragmatic in the architecture and security of their applications.

Angular (JavaScript)

Angular, developed by Google, is used to create interactive web applications. Notably, it includes tools for state management, data binding and HTTP requests. You work "in" the framework, which controls the organization and execution of your code (reverse control). This makes it a powerful yet demanding environment in terms of compliance with its conventions. AngularJS has been completely at the end of its lifespan since late 2021 and since 2016, any Angular is native Typescript.

Library

A library is a collection of reusable classes or functions that you can call to perform specific tasks. Unlike a framework, you control the integration and execution of features.

Newtonsoft.Json (C#)

This is an open-source library for the .NET framework that enables you to serialize (convert an object to JSON) and deserialize (convert JSON to an object) easily.

Selenium (Python)

Selenium is used to automate the testing of web applications, providing functions to interact with browsers, such as clicking buttons or filling out forms.

Moment (JavaScript)

Moment allows manipulation and formatting of dates and times (for example, YYYY-MM-DD).

IronPDF (C#)

IronPDF is specialized in generating, editing and retrieving PDF content.

Numpy (Python)

Numpy is a compelling part of scientific computation, including advanced mathematical functions and tools for manipulating multidimensionalarrays.

jQuery (JavaScript)

jQuery simplifies interaction with the DOM (Document Object Model) and events on web pages.

Package

A package is an organized set of modules, often grouped together in a single folder, that can be used to structure and organize code in a logical, reusable way. It can also contain other packages (subpackages), configuration files and resources. This is a NuGet (.nupkg) for C#, a pip (folder with __init__.py) for Python and a npm (folder with package.json) for JavaScript. For example, the System.Collections.Immutable package in C# provides immutable collections for .NET and the cross-env package in JavaScript allows you to set environment variables in a way that is compatible with all platforms.

Module

A module is the smallest of the four components, so you can import it to perform one-time operations. It has no complex dependencies or imposed structure. It is simply a file containing code (with extension .cs for C#, .py for Python and .js for JavaScript), such as functions or classes that you can import and use. As a reminder, a variable is a named space in memory that stores a value, a function is a reusable block of code that performs a precise action and a class is a template for creating objects that contain attributes ("proprietary" variables) and methods ("behavioral" functions). For instance, the Python math module contains basic mathematical functions, such as sqrt, sin, or log.

Understanding these differences is key to choosing the right tool for your needs. Use a framework like Angular if you're looking for an all-in-one solution to structure your project. Prefer a library like Selenium for a specialized task or a Numpy for a scientific field. Finally, modules such as math from Python are perfect for light and one-off needs. By mastering these concepts, you will optimize your approach to development, choosing the right tool for each situation. Below is a summary table to share with your software teams:


Concept Definition Use case
Framework A structured software component that provides a predefined architecture and controls application progress Developer writes code to be inserted into the intended locations and the framework executes it according to its own lifecycle.
Library An organized set of software resources (functions, classes, modules) to perform specific tasks without imposing an architecture Developer imports the library and exploit resources as needed in the application.
Package A collection of files and resources (libraries, modules, configurations) grouped and distributed through a package manager to facilitate their integration into a project Developer installs the package through the manager and then imports it into its code to use its features.
Module A file containing code (functions, classes, variables) for import and use in other files or programs Developer imports the module into another file and uses the items it provides.
